Bước tiếp theo: Pair máy cloud
  1. Mở ứng dụng Steam Link trên điện thoại hoặc PC.
  2. Chọn "Other Computer" hoặc "Pair with PIN".
  3. App sẽ hiển thị mã PIN 4 số (Pairing Code).
  4. Gửi ngay mã PIN này cho admin qua Discord (tên đăng nhập: ...).
  5. Admin sẽ pair máy → bạn sẽ kết nối được ngay sau đó.
